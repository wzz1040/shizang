# 拾藏 · 让收藏不再吃灰

知乎黑客松「校园新锐季」—— 学习工具与知识生产方向参赛作品（开发中 v1）。

**定位**：把吃灰的知乎收藏夹，变成会自动复习的个人知识系统。
**核心闭环**：导入收藏 → AI 提炼核心观点 → 自动生成复习卡片 → 间隔重复复习 → 知识周报。

---

## 一、怎么运行

**方式 A（最简单）**：直接双击打开 `index.html`，浏览器即可运行，全部功能离线可用。

**方式 B（推荐，后续接 LLM 需要）**：起一个本地静态服务器，避免浏览器对本地文件的限制。

```bash
# 任选其一（在该项目目录下执行）
python -m http.server 8000
# 或使用 VS Code 的 Live Server 插件
```

然后浏览器访问 `http://localhost:8000`。

## 二、目录结构

```
shizang/
├── index.html           # 单页应用外壳（6 个视图 + 导入弹窗 + 底部导航）
├── css/
│   └── style.css        # 设计系统（苹果式克制风）
├── js/
│   ├── data.js          # 数据层：51 条真实收藏（含全文增强）
│   ├── sm2.js           # SM-2 间隔重复算法（纯 JS）
│   └── app.js           # 应用逻辑：路由 / 列表 / 详情 / 复习 / 地图 / 周报 / 导入
└── README.md

shizang-extension/       # Chrome 插件：知乎页面一键抓取全文 → 导入拾藏
├── manifest.json        # MV3 清单
├── popup.html           # 弹窗界面
├── popup.js             # 抓取 / 生成 JSON / 复制
└── extract.js           # 正文提取逻辑（文章 / 回答两种结构）
```

**当前功能**：欢迎页 → 收藏列表（统计条 + 主题过滤 + 排序切换「最新/最早」+ 「＋导入」）→ 详情页（原文 + 「在知乎查看原文」+ AI 提炼动效 + 卡片预览）→ 复习页（答题 → 自评 → SM-2 间隔更新）→ **知识地图**（主题卡片：收藏量/提炼量/掌握率 + 「吃灰重灾区」高亮，点击主题联动过滤列表）→ **知识周报**（统计卡 + 收藏转化漏斗 + 主题转化分布 + 吃灰最久 Top3 + 今日复习清单）。导入成功弹窗可一键打开新条目详情。数据仅存本地（localStorage）。

**数据说明（v3）**：`js/data.js` 已接入真实收藏 —— 通过 Zhihu CLI 拉取当前账号收藏夹（51 条，公开范围），全部为 `pending`（待提炼），demo 从「51 收藏 / 0 掌握」开始，现场提炼。收藏数据仅存本地（localStorage），不上传任何服务器。

**关于内容来源（重要）**：知乎开放平台**不提供**收藏内容的全文接口（仅返回摘要），网页抓取也被 robots.txt 禁止。因此：

- `contentSource: "summary"` 的条目，原文区为平台摘要，页面提供「在知乎查看原文」一键跳转，数据不造假、可溯源；
- `contentSource: "full"` 的条目，为通过知乎搜索严格匹配（URL 完全一致）到的完整原文，质量更好（demo 可优先讲这几条）；
- **产品形态演进**：完整版拾藏应做成浏览器插件 —— 用户在知乎页面点「收藏到拾藏」时直接抓取当前页完整正文，彻底绕开开放平台摘要限制。**插件 MVP 已实现，见第三节。**

## 三、浏览器插件（抓取知乎全文）

**解决什么**：开放平台不提供收藏全文 → 收藏时直接抓当前页完整正文。

**安装**：
1. Chrome 地址栏输入 `chrome://extensions` → 打开右上角「开发者模式」；
2. 点「加载已解压的扩展程序」→ 选择 `shizang-extension/` 文件夹；
3. 工具栏出现「拾」图标即安装成功；
4. **（推荐，自动导入用）**在扩展列表点拾藏卡片的「详情」→ 打开「允许访问文件网址」开关。

**使用**：
1. 打开任意知乎文章（zhuanlan）或回答页，点工具栏「拾」图标 → 「抓取并生成」；
2. **自动导入**：若拾藏页面已打开（file 或 localhost），抓取后自动写入拾藏，弹窗出现「打开拾藏查看 ↗」按钮——点击直接跳转到刚导入收藏的详情页；
3. **降级**：未检测到拾藏页面时，JSON 留在弹窗里可复制，到拾藏列表页「＋ 导入」粘贴；
4. 手动导入成功后弹窗列出新条目，点击可直接打开详情。

**说明**：抓取的是页面首个回答/文章正文；提取逻辑（`extract.js`）已通过文章/回答两种结构的模拟页自动化验证；自动导入桥（`bridge.js`）写入 localStorage 并触发页面刷新，新增条目自动分类。

### 存量收藏的迁移（插件时代之前的老收藏）

插件不止能抓"当前页"，还内置了存量迁移三件套（v0.2.0）：

1. **收藏夹页面批量导入**：在知乎打开你的收藏夹页面（`zhihu.com/collection/…`），插件自动滚动加载整页，把全部收藏项（标题 + 链接 + 摘要）批量导入拾藏；已存在的链接自动跳过，不重复。
2. **浏览即回填全文**：插件在知乎页面自动运行——你浏览任何文章/回答时，若拾藏里已有同链接条目，全文自动回填（列表里字数、详情页原文立即更新）。平时正常刷知乎，老收藏就一篇篇补全了。
3. **一键批量补全**：插件弹窗「批量补全全文」→ 后台自动逐篇打开拾藏中所有摘要版收藏（约 5~10 分钟/50 篇），抓全文回填；工具栏图标显示进度 `n/总数`，可随时停止，剩余部分下次继续。

> 摘要版收藏回填全文后，详情页点「🔄 重新提炼」即可用完整正文重新生成观点与卡片（建议配合真实 LLM）。

## 四、接入你的真实收藏（69 条）

保持 `data.js` 中每条 item 的字段结构不变，替换为你的真实收藏：

| 字段 | 说明 |
|---|---|
| `id` | 唯一标识，建议 `c1, c2, ...` |
| `title` | 收藏的问题 / 文章标题 |
| `type` | `回答` / `文章` / `视频` |
| `url` | 原文链接（可选） |
| `topic` | 主题标签（用于知识地图聚类） |
| `savedAt` | 收藏日期 |
| `content` | 原文正文（AI 提炼的输入） |
| `status` | `pending`（待提炼）/ `ready`（已提炼）/ `mastered`（已掌握） |
| `corePoints` / `cards` | 提炼结果，`pending` 时为空数组 |
| `review` | SM-2 状态：`{ reps, ease, interval, due }`，新条目填 `{0, 2.5, 0, 0}` |

### 获取真实收藏的两种方式

**方式 A：Zhihu CLI（知乎官方命令行工具，推荐）**

1. 到 Zhihu CLI 官方发布页下载 Windows 预编译版本，或 `npm install -g @dawnswwwww/zhihu-cli`；
2. 按官方文档完成登录 / 配置 Access Secret（凭证仅存本地）；
3. 执行 `zhihu favorites` 拉取收藏夹内容，输出 JSON；
4. 把 JSON 映射为上面的 item 结构，粘贴进 `js/data.js`，并把 `meta.source` 改为 `"zhihu"`。

**方式 B：手动精选（demo 兜底）**

demo 其实只需要 8~10 篇有故事性的收藏。直接在 `data.js` 里替换 `title / content / topic / savedAt` 即可，几分钟搞定。

> ⚠️ 替换数据后如果页面还显示旧数据，点欢迎页的「重置演示数据」，或清掉浏览器 localStorage。

## 五、接入真实 LLM（已内置 UI）

拾藏已内置 LLM 接入（`js/llm.js`，OpenAI 兼容格式），**无需改代码**：

1. 打开拾藏 → 欢迎页点「⚙️ 配置 AI 提炼」；
2. 填入三项：**API 地址**（以 `/chat/completions` 结尾）、**模型名**、**API Key**；
3. Key 仅保存在本机浏览器 localStorage，**不会写入代码文件**；
4. 之后详情页「生成观点与卡片」自动走真实 AI（按钮变「AI 思考中…」），失败时自动降级回模拟提炼，不会卡死。

提示词：要求模型输出 `{ corePoints: [string], cards: [{ front, back, note }] }` JSON。

> ⚠️ CORS：若浏览器直调被拦截（多数大模型平台不允许网页跨域调用），改用本地代理：`npx serve` 起本地服务器 + 在服务端加一层转发（或在平台控制台开启允许跨域）。

## 六、演示脚本（3~5 分钟）

1. **开场**：展示收藏列表统计条——"我收藏了 69 条，真正回看的不到 5%。"
2. **提炼**：点开一篇 `pending` 收藏，现场生成核心观点 + 复习卡片（打字机动效 = 技术高光）。
3. **复习**：进入今日队列，做一道题，自评「记得」，展示下次复习间隔变化。
4. **收尾**：一句话升华——"让收藏从「存过」变成「学会」，这就是知识生产的起点。"

## 八、浏览器插件（可选加分材料）

插件目录：\shizang-extension/\（Manifest V3，支持 Edge / Chrome）。

**安装步骤**：
1. 下载本仓库的 \shizang-extension\ 文件夹；
2. 浏览器打开 \edge://extensions\（Chrome 为 \chrome://extensions\），开启右上角「开发人员模式」；
3. 点「加载已解压的扩展」，选择 \shizang-extension\ 文件夹；
4. 在插件详情中勾选「允许访问文件 URL」（使用本地拾藏页时需要；使用线上 Demo 可跳过）；
5. 打开拾藏页面（线上 https://wzz1040.github.io/shizang/ 或本地 index.html），浏览器会提示加载插件，确认即可。

**功能**：在知乎文章 / 回答页面点插件「抓取并生成」→ 自动提取全文并导入拾藏 → 弹窗一键跳转到刚导入的收藏；支持「批量补全全文」（后台自动打开知乎页面补全文并回填）。线上 Demo 与插件均可用。
